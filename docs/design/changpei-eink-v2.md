# 长佩阅读器 · 电纸书（E-ink）黑白设计规格书 v2

> **目标设备**：6–7 寸电子墨水屏（Android 底层），300ppi 左右，黑白 16 级灰
> **方法**：UI/UX Pro Max × Apple HIG 七步法（定气质 → 结构 → 尺度 → 色彩 → 细节 → 动效 → 验收）
> **依据**：① 长佩官网实抓 token ② 用户提供的微信读书/起点读书墨水屏截图（起点截图中的 `刷新频率`、`显示时间和电量`、`文字加粗` 三项，即为墨水屏专属设置）
> **版本**：2026-10-28（v1 的彩色青绿方案在本设备上作废）

---

## 0. 先修正 v1 的 5 个结论

上一版按"彩色手机 App"做的，在电纸书上**全部不成立**：

| # | v1 的说法 | 在 E-ink 上的现实 | v2 结论 |
|---|---|---|---|
| 1 | 默认上下滚动，更适合追更 | E-ink 滚动 = 每帧整屏重绘，会持续闪烁 + 严重残影，阅读体验灾难 | **必须分页翻，禁止连续滚动** |
| 2 | 主色 `#29CCCC` 青绿 | 黑白屏显示为脏灰；即使彩色墨水屏（4096 色、饱和度极低）也只会变成灰绿污渍 | **全灰阶，零彩色** |
| 3 | 章节末「作者有话说」用 `#F5F9F9` 淡青底 | 大面积浅灰在 E-ink 上被抖动（dithering）成**网格噪点**，看起来像屏幕脏了 | **改 1px 左竖线 + 白底** |
| 4 | 夜间模式 `#151619` | E-ink 靠前光而非背光，黑底会降低环境对比、且大面积黑转白触发全刷黑闪 | **不做夜间模式**，只保留「前光亮度」 |
| 5 | 面板 240ms 推入动画、按压 scale 反馈 | 任何过渡都会被渲染成 2 帧并存 → 重影；动画期间持续刷新 → 费电 | **零动效**，改为「瞬时切换 + 可控全刷」 |

> 保留有效的部分：三层剥离法（骨架抄微信读书 / 皮肤做黑白长佩 / 架构按追更重做），以及 4 个原创设计点（但实现方式全部改动，见 §3）。

## 1. Step 1 · 定气质：**纸感极简（Paper Minimal）**

只选一种风格，全站只准用这一套数值：

| 维度 | 规则 | 理由（E-ink 硬约束） |
|---|---|---|
| **圆角** | **2 级：0（列表/通栏）与 4px（卡片/按钮）** | 大圆角在低对比下失去轮廓感；墨水屏上「方」更清晰 |
| **阴影** | **0 档，完全不用** | 灰度阴影 = 一片脏灰，且会被抖动成噪点 |
| **描边** | **只用 1px 纯黑**（`#000`）或 0 | 浅灰描边在 E-ink 上直接消失（实测 `#EEF0F1` = 1.14:1） |
| **材质/模糊** | **禁止**（无毛玻璃、无半透明叠加） | 墨水屏无 alpha 合成，半透明=不可预测的灰 |
| **图标** | 一套库，**线宽统一 2px** | 1.5px 经灰度抗锯齿后会断续、断开 |
| **强调手段** | 只用 3 招：**反色块 / 线宽 / 形状** | 没有颜色可用 |

**反模式（本设备特有，出现即返工）**：
- 同屏出现 3 种圆角语言
- 用浅灰底块做分区（必然 dither 出噪点）
- 用颜色区分状态（在黑白屏上等于没有状态）
- 用 emoji 当图标（彩色 emoji 在 E-ink 上是一团灰块）

## 2. Step 2 · 结构

- **每屏一个主行动**：书架 → "继续阅读"；详情 → "开始阅读"；阅读器 → 无（阅读本身就是行动）
- **分层只用 3 种手段，且不叠加**：留白（>24px）/ 1px 黑线 / 缩进
- **渐进披露**：阅读器工具栏默认隐藏，点击中间区才出现
- **减少输入**：E-ink 键盘输入慢且每次按键都刷新 → 搜索入口降级为次级，优先「分类/榜单/书单」浏览
- **去掉一切持续变化的元素**：不跟随滚动的浮层、不做呼吸动画、loading 用静态文字「加载中…」而不是旋转 spinner（旋转 = 持续重绘 + 残影 + 费电）

## 3. Step 3 · 尺度（E-ink 特化，覆盖通用阶梯）

通用阶梯是 12/14/16/18/24/32，正文 16px 基准。**墨水屏阅读场景要整体上浮**：

| 项 | 通用值 | **E-ink 值** | 依据 |
|---|---|---|---|
| 正文基准 | 16px | **20px**（可调 18/20/22/24） | 6–7 寸屏 + 30–40cm 阅读距离，16px 会吃力 |
| UI 正文字号 | 16 | **16**（下限，不得更小） | Apple HIG：<16px 在移动端是硬伤 |
| 行长 | 35–60 字 | **30–40 字** | 减少眼跳，E-ink 无光标跟随 |
| 行高 | 1.5–1.75 | **1.75**（可调 1.6/1.75/1.9） | 灰底阅读疲劳，需要更松 |
| 间距 | 4 的倍数 | **4 / 8 / 16 / 24 / 32**，同级必须一致 | 通用规则照旧 |
| 触控热区 | 44 / 48 | **≥48×48dp，间隔 ≥12dp** | E-ink 触控采样低、易丢点 |
| z-index | 0/10/20/40/100/1000 | 同 | 禁止 9999 |

字号阶梯（落成 token，禁止 13.5 这类值）：

```css
--fs-caption: 13px;  /* 仅用于时间戳、角标，且颜色必须 ≥4.5:1 */
--fs-body-s:  15px;  /* 次要信息 —— 极克制使用 */
--fs-body:    16px;  /* UI 正文下限 */
--fs-title:   18px;
--fs-h:       22px;
--fs-big:     28px;
--fs-read-min:18px;  /* 阅读器最小字号 */
--fs-read-def:20px;
--fs-read-max:24px;
```

## 4. Step 4 · 灰阶系统（替代"色彩"这一步）

### 4.1 实测对比度（这是本规格书最重要的一张表）

| 用途 | 色值 | 对比度 | 判定 |
|---|---|---|---|
| 正文 / 主图标 | `#000000` | **21.00:1** | ✅ 首选 |
| 长佩官网正文 | `#333333` | 12.63:1 | ✅ 可用，但 E-ink 上建议直接上纯黑 |
| 次要文字 | `#555555` | **7.46:1** | ✅ 安全 |
| 最弱文字（下限） | `#767676` | **4.54:1** | ✅ 4.5 临界，不得更浅 |
| 微信读书副标题 | `#8A8A8A` | 3.45:1 | ⚠️ 只够大字/非文字 |
| **长佩 `--fg-light`** | `#8D99A6` | **2.90:1** | ❌ **在墨水屏上会糊掉，禁用** |
| 浅灰 | `#9B9B9B` | 2.78:1 | ❌ 禁用 |
| 禁用/边框灰 | `#B0B0B0` | 2.17:1 | ❌ 不能做边框 |
| **长佩分隔线** | `#EEF0F1` | **1.14:1** | ❌ **等于不存在** |

> 结论：**长佩官网的品牌灰和分隔线不能直接搬**。这是"品牌一致性"和"可读性"冲突时的取舍——在电纸书上，可读性优先。

### 4.2 最终灰阶 token（只用 4 档）

```css
:root{
  --ink:      #000000;  /* 正文、主标题、主图标、1px 描边 */
  --ink-2:    #555555;  /* 次要文字：作者、时间、章节数（7.46:1） */
  --ink-3:    #767676;  /* 最弱：仅用于非关键说明，字号 ≥15px（4.54:1） */
  --paper:    #FFFFFF;  /* 唯一底色，不做灰底分区 */
  --reverse-bg:#000000;
  --reverse-fg:#FFFFFF;
}
```

**只有 4 个值，其余全部由「线、留白、字号、位置」表达。**

### 4.3 分层规则（替代原来的"浅灰底块"）

| 想表达 | ❌ 不要用 | ✅ 应该用 |
|---|---|---|
| 区块分组 | `#F5F6F7` 灰底块 | 24px 留白，或 1px `#000` 通栏线（上下各留 16px） |
| 当前章节 | 淡青底 / 淡灰底 | **左侧 3px 纯黑竖条** + 文字加粗 |
| 未读状态 | 彩色圆点 | **实心黑圆点 6px**（已读则无点） |
| 选中项 | 彩色 | **反色块**（黑底白字）或 **2px 黑描边**（二选一，不叠加） |
| 强调/主按钮 | 品牌青 | 黑底白字，圆角 4px |
| 次要按钮 | 灰底 | 1px 黑描边 + 白底 |

## 5. Step 5 · 细节

### 5.1 图标
- 一套库（推荐 Lucide），**线宽统一 2px**，尺寸 token：20 / 24 / 28dp
- 同一层级不混用填充与描边；Tab 激活态可以用**填充**表达，但同层其余必须全描边
- 触控热区不足 48dp 时用透明 padding 补齐，视觉尺寸不变

### 5.2 文字
- 中文避头尾：`line-break: strict; word-break: normal;`
  **必须做**——否则出现「。」居行首（你现有原型就有这个 bug）
- 数字全部 `font-variant-numeric: tabular-nums`（书币、字数、进度防跳动）
- 价格/单位用不换行空格（`8.00 书币` 不拆行）
- 长标题 `overflow-wrap: anywhere`，正文不用 `break-all`
- 提供「文字加粗」开关（E-ink 细字重会发虚，用户可补偿）——起点截图里就有这一项

### 5.3 图片
- 所有封面/插图预处理为**灰度**，对比度 +10~15%（E-ink 对比度天生偏低）
- **禁止在图片上叠半透明蒙层**（例如"已读"蒙版），E-ink 上会糊成一片灰；改用**角标**（黑底白字小方块）表达

### 5.4 边框与线
- 分隔线用 `1px solid #000` 太抢？**不要降成浅灰**（会消失），改为：
  - 降低视觉重量用 **虚线**（`1px dashed #555`），或
  - 干脆**用留白代替线**（E-ink 上留白是最干净的分隔手段）

## 6. Step 6 · 动效 → 替换为「刷新策略」

E-ink 没有"动效"，只有"什么时候刷屏"。这一节替代通用动效规范。

### 6.1 铁律

| 规则 | 说明 |
|---|---|
| **零 CSS transition / animation** | 过渡帧会被渲染成两帧并存 → 重影；`@keyframes` 持续刷新 → 费电 + 残影 |
| **按压反馈用「立即变化」** | 不做 scale、不做阴影，直接切反色（`background` 从 `#fff` 变 `#000`），时长 0 |
| **尽量缩小重绘面积** | 翻页只改正文容器；工具栏用 `visibility` 而非 `display`，避免重排 |
| **禁止固定定位的持续变化元素** | 跟随进度的浮动条、呼吸动画、转圈 loading 全禁 |
| **输入框不自动聚焦** | 光标闪烁 = 持续局部刷新 |

### 6.2 翻页（核心）

```
点击右 1/3 → 容器 textContent 整体替换 → 只标记正文区重绘 → 结束
```
- 无滑动跟手、无淡入淡出、无 3D 翻页
- 页与页之间**绝对不重叠、不位移**（位移必然产生中间帧）
- 若为原生 App：调用局刷 API，只刷正文矩形区

### 6.3 全刷（去残影）

- 每 N 次翻页执行一次全屏刷新（黑闪一次），清除累积残影
- **必须做成用户可选项**：`刷新频率 1页 / 5页 / 10页 / 20页 / 永不`（默认 10 页）
- 位置：阅读器「更多设置」内（与起点截图一致）
- Web 端无法控制局刷/全刷，只能通过「减少重绘」间接优化；建议此项目用 **Capacitor / Android WebView + 原生刷新接口**，否则永远是残影

### 6.4 面板出现/消失

- 不做推入动画，**直接 show / hide**
- 面板出现时正文区不重排（用覆盖层，且覆盖层为纯白不透明）

## 8. 长佩品牌 → 灰阶 映射表（落地用）

| 原品牌元素 | 彩色做法（作废） | **E-ink 做法（采用）** |
|---|---|---|
| 主色 `#29CCCC` | 主按钮/选中/图标激活 | → **黑底白字**（主按钮）、**黑下划线**（Tab）、**实心黑点**（未读） |
| 深青 `#2DB1B4` | 链接/正文强调 | → `#000` + **下划线** |
| `rgba(45,177,180,.14)` | 选中项淡底 | → **左侧 3px 黑竖条** 或 **1px 黑描边** |
| `#FAFBFC` 页面底 | 冷灰白底 | → 统一 `#FFF`（E-ink 上 `#FAFBFC` 和 `#FFF` 无法区分） |
| `#EEF0F1` 分隔线 | 1px 浅灰线 | → 24px 留白，或 `1px dashed #555` |
| `#8D99A6` 次要字 | 说明文字 | → `#555`（7.46:1） |
| `#F5F6F7` 按钮底 | 次按钮 | → 白底 + 1px 黑描边 |
| 4px 圆角 | 卡片圆角 | → **保留**（4px 在 E-ink 上依然清晰） |
| 深色主题 `#151619` | 夜间模式 | → **删除**，只保留前光亮度调节 |

## 11. 一句话总结

> 在电纸书上，**设计不是"少用颜色"，而是"重写一套只有黑白灰的语法"**：
> 分层的工具从「色块」变成「留白与线」，强调的工具从「颜色」变成「反色与线宽」，
> 动效的工具从「过渡」变成「刷新策略」。长佩的品牌感不靠青绿，靠**安静、克制、字距与留白**。
