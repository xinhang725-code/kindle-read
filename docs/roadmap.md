## 2. 功能验收清单

下表全部为**待执行**，不是当前测试结果。「必需」指完整首版目标；「条件项」由实际公布的支持范围和用户要求确定。

| 编号 | 要求 | 级别 | 操作与预期 |
| --- | --- | --- | --- |
| A01 | 原生书架入口 | 必需 | 重启设备后，原生书架可见项目入口；点一次进入项目，途中不需操作 KUAL/文件管理器 |
| A02 | 首次启动与续读 | 必需 | 无记录显示空书架；有记录直接打开最近正文，可返回应用书架 |
| A03 | 添加真实起点作品 | 必需 | 输入有效链接/ID 后显示正确书名、作者和有序目录；无效输入给出可理解提示 |
| A04 | 真实免费正文 | 必需 | 目录选章，核对官方同章的标题、开头、结尾及正文完整性；章节无重复、乱码或遗漏 |
| A05 | 正文阅读与跨章 | 必需 | 翻页及调字号正常；章末进入下一章；目录定位正确，无重复或跳过章节 |
| A06 | 正常保存位置 | 必需 | 退出、休眠、重启后回到同一段落；改变字号后仍可定位 |
| A07 | 目录更新 | 必需 | 检查更新后新增章节顺序正确，旧位置不重置；真实更新可观察时补充真实来源验证 |
| A08 | 缓存与离线 | 必需；仅限允许缓存的内容 | 飞行模式下打开已缓存章节；未缓存章明确提示联网，不破坏现有正文 |
| A09 | 网络故障 | 必需 | 请求超时、断网、限流及访问挑战均能退出等待，保留阅读状态；不会无限重试 |
| A10 | 写入中断与空间不足 | 必需 | 中断写入不产生伪成功缓存；空间不足可恢复，书架和进度保留 |
| A11 | 正常登录及过期 | 声称账号支持时必需 | 实际完成登录，正确显示状态；会话过期时提供可行的恢复流程 |
| A12 | 已购与未购章节 | 用户要求 VIP 或声称支持时必需 | 已购章经核对完整可读；未购章显示权限状态；应用不触发购买 |
| A13 | 账号隔离与登出 | 声称账号支持时必需 | 切换账号不能复用另一账号的私有正文；登出后会话和私有缓存清理正确 |
| A14 | 休眠与系统恢复 | 必需 | 正文休眠/唤醒可继续；退出后系统书架与输入恢复；休眠时无项目轮询 |
| A15 | 重复启动与已有宿主 | 必需 | 重复点击不产生多个相互争用的阅读进程；已有 KOReader 时行为明确 |
| A16 | 安装及卸载 | 必需 | 依说明可完成安装/卸载；旧书籍和宿主设置保留；项目项不会残留为无法打开的条目 |
| A17 | 原有 KOReader 使用 | 采用插件方案时必需 | 普通 KOReader 启动按原设置工作，项目一次性入口意图不长期劫持宿主 |
| A18 | 性能与耗电 | 必需 | 按设计中的冷启动、翻页和休眠测量方法记录结果，公布实际支持设备上的限制 |

真实来源暂时无法产生章节更新时，可以用夹具验证更新算法，但记录为“算法通过，真实更新待验证”，不能把两者混写。

## 3. 验证分层

- **纯逻辑测试**：URL/ID 校验、目录合并、错误分类、稳定位置映射、缓存淘汰与版本迁移。使用自造或可合法公开的夹具。
- **宿主集成测试**：插件初始化、阅读器切换、跨章、普通宿主入口行为、安装布局。电脑模拟器通过只证明这一层。
- **真实来源检查**：免费正文完整性、真实登录流程、已购/未购区别、权限和会话变化。按需运行，避免 CI 反复请求平台或存放账号凭据。
- **Kindle 实机测试**：原生入口、中文排版、触控/按键、刷新、休眠、系统恢复、安装/卸载。由实际设备完成，不以浏览器截图代替。

每次测试记录版本、设备、内容类型、步骤、预期、实际结果和证据。通过、失败、阻塞、未执行、不适用分别标记；不把没有执行的测试记为通过。
