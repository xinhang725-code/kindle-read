用户已授权继续实现，补充强制扫码登录（未登录不能使用），并提供《长佩阅读器-电纸书黑白设计规格书-v2》。目标仍为 KPW5 / Vera 原生书架入口，不依赖 KOReader。微信读书、起点工作暂停。

沿用 Go helper + ES5 Mesquite；规格书的 Android / Vue 原型段落不是更换设备或使用 mock 内容的要求。设计原文见 `../../design/changpei-eink-v2.md`。

## Review focus

取消/重新扫码的竞态；不能信任 HTTP 200、二维码已扫或有密文就代表有阅读权限；头部 gRPC 错误不能忽略；未知协议字段及受损数据不能崩溃；字号与翻页不丢字、不漂移书签；未验证设备功能不得显示虚假的成功状态；安装源过滤不得删改其他入口。

本轮不把未做功能标为完成：真实账号扫码确认、已购章节和 KPW5/Vera 需要实机验收；官方验证码尚需适配；云端书架/进度、评论、充值、听书和前光/物理全刷另行验证与接入。

用户说明新 C/LVGL 文档是 DeepSeek 的候选方案，技术路线由本项目评估，不要求照搬架构。采用其屏幕布局与结构化正文要求，继续本机 Go + ES5 / Mesquite；不引入必须维护的远程服务。默认先登录，过期重新扫码；这不能绕过官方验证或购买限制。偏移使用 UTF-16 code units，与现有阅读进度一致。
