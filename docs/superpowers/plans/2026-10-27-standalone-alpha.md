# 三个独立应用：首个可运行开发版本

**Goal：** 开始实现三个无 KOReader 依赖的应用，交付可复现构建、电脑端可运行程序及 KPW5 ARM 测试包。推进 M1；不以本轮的协议夹具和桌面验证宣布 M1/M2 真机、真实来源验收通过。

**Architecture：** Kindle 内置 Mesquite 承载 ES5 界面；静态 Go ARM 程序提供仅绑定回环地址的私有 HTTP 服务，负责 HTTPS、来源隔离、持久化及退出。Vera Scriptlet → appmgr → 每个应用自己的 Mesquite ID。界面不经二级应用选择器。

**Tech Stack：** Go 1.25.3（CGO=0、linux/arm、GOARM=7）、HTML/CSS/ES5、Node 内建测试；Go 标准库和固定版本的 HTML/QR 依赖。系统运行前置为 Mesquite、sqlite3、lipc-set-prop 和 Vera Scriptlets，是否具备由预检和实机确认。

**Spec：** [设计](../specs/2026-10-27-kindle-qidian-design.md)、[MiuRead](../../miuread-porting.md)。

**Global Constraints：** 不加载/捆绑/下载 KOReader；不修改系统根分区或其他应用；平台、账号、进度、缓存隔离；所有外部请求使用限定 HTTPS 主机，限制重定向、响应大小和时间；不购买、不绕过权限；敏感字段不进入日志；夹具不进入用户书架；失败不覆盖已有数据；上游移植遵守 AGPL-3.0-only 并保留归属。

**Review Focus：** 无真实平台或真机结果时的状态诚实性；持久化失败与并发；本地服务鉴权/重定向；重复启动及安装失败恢复；中文分页的字符完整性；MiuRead 是否有真实业务移植而非改名空壳。
