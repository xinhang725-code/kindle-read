# 长佩阅读 0.2.0-alpha.1

开发测试包，目标 KPW5 / Vera；没有 Kindle 实机验收结果。无需 KOReader、KUAL、Node 或单独服务器。真实手机授权、已购正文和设备入口仍待验证。

## 安装

1. 解压 `changpei-0.2.0-alpha.1-armv7.zip`，把 `documents` 和 `extensions` 两个目录合并复制到 Kindle USB 根目录。
2. 安全弹出 USB，在原生书架点击「安装长佩阅读测试版」。程序检查系统组件、注册长佩应用并添加入口。
3. 点击「长佩阅读」。首次打开显示二维码，用 **长佩阅读 App → 我的 → 扫一扫**，在手机上确认。不是微信扫码。
4. 登录后从「逛书城」榜单选择作品，或搜索书名/作者、输入官方作品编号。作品保存在应用内，不逐本写入 Kindle 原生书架。
5. 阅读时左侧上一页，右侧下一页，中间显示工具栏。工具栏可返回、打开目录、调整字号、行距、边距、加粗和首行缩进。

若书架不显示安装入口，停止安装，先核实固件与 Vera 是否启用了 Scriptlets。本包未使用旧 `.azw2`/KDK 壳，不自动安装其他启动工具、不改系统根分区。

有 SSH 且已确认运行组件时，对应命令为：

```sh
/mnt/us/extensions/kindle-read/bin/kindle-read preflight changpei
/mnt/us/extensions/kindle-read/bin/kindle-read install changpei
```

组件预检通过不等于原生书架索引、旧 WebKit、触摸、刷新或休眠已通过。

## 账号与内容

- 未登录不能进入书架、搜索、正文和缓存接口；重启校验已保存会话，失效时重新扫码。
- 二维码过期、拒绝授权或网络中断后，可以点「刷新二维码」。退出/切到后台会取消未完成的扫码。
- 登录不能消除官方验证码、锁章、已购权益或 App 专属限制。遇到限制会显示原因，不把密文或试读当作完整正文。
- 当前书架是**本设备的账号书架**，尚未同步长佩云端收藏、阅读进度。只自动缓存已打开章节，每账号最多 100 MiB。
- 网络不可用时保留已提交缓存和进度；重新启动需要验证会话，当前不承诺离线重启阅读。
- 退出账号会清除此账号在本设备的缓存和进度。凭据仅保存在 helper 的私有文件，不发给页面；Kindle USB 分区的权限不能替代设备物理保管。
- 前光使用 Kindle 系统设置。物理局刷/全刷控制、封面、图文特殊章节、评论、听书、充值尚未接入。

## 卸载

先退出应用，点击「卸载长佩阅读入口」，或执行 `.../bin/kindle-read uninstall changpei`。仅卸载长佩的注册和入口，保留数据，不修改起点/MiuRead 入口。确认不需要数据后可自行删除对应文件。

若同目录已装过 Kindle Read，本包共用 `extensions/kindle-read/bin/kindle-read` 并升级该 helper；其余应用注册不变。拷贝前先退出所有 Kindle Read 应用。遇到已被手动修改的入口，安装器会拒绝覆盖。

对应源代码和依赖许可证已随包提供。完整技术边界见 [实现状态](implementation-status.md)。
