# kindle-read

面向已越狱 Kindle 的起点与长佩文学阅读项目。

目标体验：Kindle 原生书架上显示「起点阅读」「长佩阅读」两个入口，点开即可进入对应阅读流程；有记录时优先续读，无记录时进入该平台的应用内书架。双入口为当前设计建议，名称暂定，不代表平台官方客户端。

**当前阶段：项目文档修订稿。尚未实现应用，也未完成 Kindle 实机及起点、长佩的内容访问验证。**

## 已确认的技术约束

用户明确的目标：**在使用 Vera 越狱的 KPW5 上，从原生书架点开即可使用的阅读 app，不依赖 KOReader**。原先推荐的 KOReader 插件方案已撤下；后台捆绑或隐藏 KOReader 界面不满足此约束。

用户已确认所指项目为 [MiuRead / miuread-koreader](https://github.com/miumiupy98-art/miuread-koreader)，并说明希望得到“书架点开即用”的效果。该项目依赖 KOReader 且面向微信读书。本稿据此采用**独立阅读应用**方向，MiuRead 作为交互参考；不直接把它作为运行基础，也不把内容目标从起点换为微信读书。

独立应用的启动、排版、墨水屏和休眠能力需要分别实现或选用合适组件。产品实现前先做最小验证：

1. 独立应用能够在不安装、不加载、不捆绑 KOReader 运行时的条件下运行。
2. 点击原生书架里的项目入口，能直接进入指定阅读界面，并正常退出回到系统。
3. 分别通过起点、长佩的可用访问方式取得并显示真实章节，明确各自的免费、登录和已购章节支持情况。

上述要求不能用隐藏依赖、模拟数据、普通电子书导入或多级启动菜单替代验收。

首轮验证设备为 **KPW5（Kindle Paperwhite 5），使用 Vera 越狱**，尚未完成实机验证。完整固件版本、Vera 版本、可用启动方式，以及是否要求首版支持已购 VIP 章节，仍待确认。MiuRead 项目身份已明确；MiuRead 和 KOReader 均不是安装前置条件。

## 双平台范围

用户已确认也开发长佩阅读功能。当前设计是两个书架入口共用独立阅读基础，内容适配、账号会话、付费权益、缓存与进度按平台隔离；两个平台分别验收，不能用起点接入成功代替长佩验证。
