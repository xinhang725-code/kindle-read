# kindle-read

面向已越狱 Kindle 的起点小说阅读项目。

目标体验：Kindle 原生书架上有一个「起点阅读」入口，点开即可进入阅读；有阅读记录时优先续读，无记录时进入应用内书架。名称为项目暂定展示名，不代表起点官方客户端。

**当前阶段：项目文档初稿。尚未实现应用，也未完成 Kindle 实机与起点内容访问验证。**

## 当前建议

优先评估「原生书架启动入口 + KOReader 插件 + 起点内容适配」的组合，复用 KOReader 的中文排版与墨水屏阅读能力。独立阅读器和官方网页入口作为对照方案。

这只是推荐方向，尚未确认最终技术路线。开始产品开发前，先在目标 Kindle 上验证：

1. 点击原生书架里的项目入口，能直接进入指定阅读界面，并正常退出回到系统。
2. 可以通过可用的起点访问方式取得并显示真实章节，明确免费章节和登录后已购章节各自的支持情况。

两项都不能用模拟数据、普通电子书导入或多级 KUAL 菜单替代验收。

目标机型、固件、现有越狱工具，以及是否要求首版支持已购 VIP 章节，仍待确认。文档中的默认建议均已标注；开发验证可以先从免费章节开始，但不因此宣称完整起点阅读目标已经达成。
